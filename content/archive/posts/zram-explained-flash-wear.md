## 一句话
**ZRAM = 把一段内存做成「压缩的交换区」。** 换出去的页先压缩、再存回内存——**用 CPU 时间，换可用的内存空间。**

注意：它**不是**"凭空多出内存"，是**把冷数据压小**。压缩率越高、冷数据越多，收益越大。

## 一、原理：从"换出到磁盘"到"压缩留在内存"

传统 swap 的逻辑是：内存不够 → 把不常用的页**写到磁盘** → 腾出内存。

ZRAM 换成：内存不够 → 把不常用的页**压缩** → **仍然留在内存里**（放在一块压缩块设备 `/dev/zram0` 上）。

```bash
# 看 ZRAM 设备
zramctl
# 看 swap
cat /proc/swaps
```

内核把 ZRAM 当成一个**块设备**，当 swap 用。区别只是：**写进去的数据被压缩，读出来时解压**——**全程在 RAM 里，不碰 Flash。**

## 二、为什么能"省内存"

关键在于：**被换出去的页，往往是"可压缩"的**。

- 大量**零页**（未使用的匿名页）；
- 文本/日志/配置类冷数据（压缩比高）；
- 已经不再活跃的缓存。

假设压缩比 **3:1**：
- 换出 **100MB** 冷数据；
- 压缩后实际只占 **~33MB** RAM；
- 等效"多出"约 **67MB** 可用内存。

所以 ZRAM 的收益不是线性的——**它取决于你的数据有多"好压"**：
- 文本、日志、代码 → 压缩比高（2–4×）；
- 已压缩数据（图片、加密、视频）→ 压缩比接近 1，**基本白费 CPU**。

## 三、代价：CPU、延迟、以及"别压过头"

ZRAM 不是免费的：

- **CPU**：每次换出/换入都要压缩/解压；
- **延迟**：实时性敏感的业务，换页会带来抖动；
- **压缩算法**：`lzo` / `lz4` / `zstd` 各有取舍（速度 vs 压缩率）；
- **大小**：ZRAM 大小可以超过物理内存（因为压缩），但**别当成"无限内存"**。

```bash
# 常见：装 zram-swap 后看设备与压缩情况
opkg install zram-swap
zramctl
cat /proc/swaps
vmstat 1 5        # 看 si/so（换入/换出）是否频繁
```

**判断标准**：如果 `si/so` 长期为 0，说明"够用，ZRAM 没被用上"；如果频繁换入换出、CPU 飙高，说明**压过头了**。

## 四、那为什么不用 Flash 做 swap？——因为写寿命

这是很多人忽略的：**Flash 有写入寿命（P/E cycles）。**

- NAND 每个块能擦写的次数有限：SLC 高、MLC 中、TLC/QLC 低（大致从十万次到几百次的量级）；
- **swap 是高频、随机、小块的写**——正是最伤 Flash 的模式；
- 加上 FTL / 垃圾回收 / wear leveling，**写入放大会进一步加速磨损**；
- 性能也差：随机写比 RAM 慢几个数量级。

**所以：拿 Flash 当 swap，是在"拿设备寿命换内存"**——短期看能用，长期会把 Flash 写坏。

**ZRAM 的聪明之处就在这里**：交换发生在 **RAM** 里，**RAM 没有写入次数限制**。用 CPU 换空间，而不是用寿命换空间。

## 五、ZRAM vs zswap vs swapfile（别搞混）

| 方案 | 数据最终在哪 | 特点 |
|---|---|---|
| **swapfile/分区（Flash）** | **Flash** | 省内存，但**伤寿命**、慢 |
| **zswap** | 先压缩在 RAM，**最终仍可能写盘** | 是"缓存"，不是"纯内存" |
| **ZRAM** | **RAM（压缩）** | **不碰 Flash**，纯拿 CPU 换空间 |

对路由器/嵌入式：**优先 ZRAM，避免在 Flash 上开 swap。**

## 六、怎么验证有没有用

别只看"开了没开"，要量：

```bash
zramctl                    # 压缩前后大小、压缩率
cat /proc/swaps            # swap 用量
vmstat 1 5                 # si/so 频率
cat /proc/meminfo          # SwapTotal / SwapFree
```

结合总纲里的 **PSS**（而不是 RSS）看"真实占用"，才能判断 ZRAM 到底帮你省了多少。

## 一句话

> **ZRAM 用 CPU 换内存；Flash swap 用寿命换内存。** 对要跑十年的设备，答案很清楚。
