# 素材随手记（攒素材 = 攒选题）

> 平时做项目时**顺手记一行**。发布时**不用回忆、不用重做**，直接把当时的记录变成内容。
> 位置建议：`growth/capture-log.md`（本文件的模板照抄进去），或你的笔记 App。

## 一行模板

```
YYYY-MM-DD | 在做什么 | 卡在哪 / 解开了什么 | 关键数字 | 截图/日志路径 | 可做选题
```

## 字段说明
- **关键数字**：耗时、温度、功耗、TOPS、MB/s、错误码……**数字就是钩子**。
- **截图/日志路径**：放在固定目录（如 `~/capture/2026-09-27/`），发布时直接找。
- **可做选题**：当场想到的标题/角度，哪怕粗糙。

## 示例

```
2026-09-27 | 编译 Jetson 镜像卡死 | 疯狂换页：load 19→5，任务 3.6→32/分 | pswpout 58GB | ~/capture/0927/vmstat.txt | 《7GB 内存编译卡死：一眼看出疯狂换页》
2026-09-27 | 查 nvcc 为什么慢 | nvcc 要特定 host GCC → 额外编了 gcc-for-nvcc 13.2 | GCC 16 不被认 | ~/capture/0927/nvcc.md | 《Jetson 编译为什么这么慢》
2026-09-27 | qemu 冒烟 | 镜像起不来：.zst 需 snapshot 模式 | exit 124 / 124s | ~/capture/0927/boot.log | 《虚拟板启动踩坑》
```

## 习惯（0 额外成本）
- 每做完一次实验，**花 1 分钟记一行**；
- 素材攒到 3 条 → 写进 `topics.md` 对应赛道末尾；
- 想发时：从 `topics.md` 取一条 → 回 `capture-log.md` 找数字和素材 → 直接成稿。
