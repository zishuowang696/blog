# 商业路线：用嵌入式 / 边缘 AI 能力服务商业客户

目标：把嵌入式 Linux / 边缘 AI 的能力**产品化**，直接服务商业客户。
一句话结论：**市场买的是"能兜底的人"。** 你的深度经验和真实项目，正是中小硬件公司最缺、又请不起大团队的东西。

---

## 1. 能卖什么（服务清单）

| 服务 | 客户痛点 | 交付物 |
| --- | --- | --- |
| **BSP / Yocto 定制** | 板子要跑自己的系统，厂商 BSP 太旧/太重 | 可复现的发行版（如 `embedai` 模式）、镜像、文档 |
| **Jetson 边缘 AI 部署** | 模型上板、TensorRT 优化、容器化、开机自启 | 推理服务、性能报告、部署脚本 |
| **嵌入式 Linux 排障/救砖** | 启动失败、驱动/设备树、升级变砖 | 根因报告 + 修复 + 防复发方案 |
| **架构评审** | 方案选型（Yocto vs Buildroot、容器 vs 裸机） | 评审报告 + 路线建议 |
| **边缘 AI 网关集成** | 路由器 + 算力盒的转发/推理分离 | 端到端方案（OpenWrt + Jetson） |
| **企业培训** | 团队要上手 Yocto / Jetson | 课程 + 实验环境 + 讲义 |

> 起步建议：先卖**"排障 + BSP 定制"**（痛点明确、周期短、易验证），再往**"方案 + 长期顾问"**走。

## 2. 客户画像（谁付钱）

- 硬件/AI 创业公司：有产品没资深系统工程师
- 工业物联网、机器人、AI 摄像头、边缘网关厂商
- 系统集成商：接了大项目，缺底层能力
- 海外中小团队：愿意远程付费，单价高（Upwork/Toptal/LinkedIn）
- 大型项目外包/驻场：稳定但压价，作为过渡现金流

## 3. 你凭什么（资产）

- **真实仓库**：`embedai`（可复现 Jetson 发行版）——最好的"活简历"
- **内容账号**：GitHub / YouTube / 抖音（见 `growth/`），持续证明"在解决问题"
- **行业履历**：多年复杂系统经验 = 可信度
- **可复现案例**：每篇内容/每个 Release 都是证据

## 4. 商业模式与定价（方法，不写死数字）

| 模式 | 适用 | 要点 |
| --- | --- | --- |
| 按时（时/日） | 排障、评审、咨询 | 定"最低起订量"，避免碎片化 |
| 项目制 | BSP/镜像/部署 | 明确范围 + 验收标准 + 变更另计 |
| 月度顾问 | 长期陪跑 | 固定小时/月 + 响应时效 |
| 培训 | 团队能力建设 | 按天/按班；可复用到产品 |
| 分成/联合 | 早期产品 | 谨慎，合同写清 IP 与退出 |

定价锚点：**海外 > 国内**；先用国内小单验证流程，再逐步接海外远程单拉高单价。

## 5. 获客漏斗（内容 + 直接触达）

```
GitHub/YouTube/抖音 内容
        ↓  私信/邮件/评论
      线索
        ↓  30 分钟免费诊断
    报价/方案
        ↓
      成交 → 案例 → 更多内容
```

- **平台**：Upwork、Toptal、程序员客栈、猪八戒、稀土掘金（技术社区）
- **定向 outreach**：每周联系 5 家目标公司（硬件创业、AI 摄像头、机器人、网关）
- **口碑**：每个项目结束要一句推荐语 + 允许写案例（脱敏）

## 6. 推进节奏（循序渐进）

| 阶段 | 目标 | 关键动作 |
| --- | --- | --- |
| 0–12 个月 | 资产 + 验证 | 内容稳定周更；GitHub 打底；接 2–3 个小单练流程 |
| 12–24 个月 | 稳定现金流 | 固定 1–2 个回头客；海外平台起步；案例库 |
| 24–36 个月 | 扩大规模 | 客户/收入可预期；主体、合同、税务就绪；可考虑团队化 |

**原则**：先小单验证流程与定价，再逐步扩大；不追一次性大单，追可复用的长期客户。

## 7. 红线与风险（务必确认）

- **竞业/保密协议**：确认合同条款，别踩线。
- **绝不使用**现职资源、代码、IP、工作时间做私活。
- 一切建立在**开源与个人时间**上（你的 `embedai` 正是开源资产）。
- 客户集中度：避免单一客户占收入 >50%。
- 收款/税务：提前了解个体户/公司主体与开票方式。
- 法律与税务建议请咨询专业人士。
